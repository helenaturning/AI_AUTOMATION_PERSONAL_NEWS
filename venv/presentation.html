La Problématique

  • Surcharge d'information : Impossible de lire tous les flux RSS Tech & IA quotidiennement.
  • Généricité : Les newsletters standardisées manquent de personnalisation.
  • Solution : Créer un agent conversationnel qui apprend les goûts de l'utilisateur pour générer une curation d'actualités 100% sur-mesure et automatisée.

L'Architecture (Modularité n8n)

Comme pour l'architecture Core/Plugins d'un processeur graphique, nous avons séparé les entités logiques :

  • Binôme 1 (Le Cerveau Front) : Un webhook conversationnel responsable de l'authentification et de la construction du profil.
  • Binôme 2 (Le Cerveau Back) : Un pipeline d'abstraction tirant des requêtes HTTP (RSS), filtrant par IA, et expédiant le résultat.
  • La Mémoire Partagée : Un bus de données unifié (`DemoPersona`) qui permet la communication asynchrone entre le Front et le Back.

Détail : Agent Conversationnel

  • Modèle : Google Gemini (optimisé pour le dialogue et la politesse).
  • Logique Conditionnelle : Barrière de sécurité structurée via un nœud IF conditionné par un mot magique [DONE].
  • Extraction Multi-formats : L'agent extrait en temps réel la date ISO (via $now) et les variables utilisateurs.

Détail : Pipeline de Curation

  • Ingestion de Données : Nœuds RSS standards pour TechCrunch et Simplecast.
  • Modèle Back : Groq (Llama 3) choisi rigoureusement pour sa vitesse d'Inference fulgurante sur les gros blocs de texte (Batches).
  • Synchronisation Temporelle : Nœud "Wait" dynamique qui utilise une expression Regex pour parser le HTML et bloquer l'envoi jusqu'à l'heure exacte.

Fonctionnalités Poussées & Bonus

🎙️ Personnalisation du Ton

L'utilisateur choisit le ton dans le Chatbot (Pirate, Geek...). L'Agent 2 l'applique dynamiquement sans BDD externe.

🌍 Choix de la Langue

Traduction automatique des flux RSS anglophones dans la langue sélectionnée par l'utilisateur.

📉 Indice de Sentiment

Le LLM calcule l'Indice Moral du monde de la Tech et l'inclus à la fin de la newsletter.

🛡️ CSS Fantôme (Hacking)

Inclusion du routage email (`To Address`) via un tag HTML invisible pour l'analyse par le nœud d'envoi.
